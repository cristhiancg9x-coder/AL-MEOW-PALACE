# 🏰 Al-Meow Palace — El Trono de los Jeques & Santuario Real Felino

> **Plataforma filantrópica de ultra-lujo con estética de Dubái para el cuidado de 9 felinos de la realeza y la fundación de una Finca Santuario.**  
> *Creado & Liderado por **Mr. Gean**.*

---

## ✨ Características Principales

- **🏛️ Estética de Ultra-Lujo (Dubai Style):** Paleta obsidiana profundo, oro metálico (`#D4AF37`) y acentos verde esmeralda imperial.
- **🪐 Escena 3D Ultraligera (Three.js):** Joya facetada de oro procedural (`IcosahedronGeometry`), anillo orbital doble y campo de polvo estelar de 300 partículas con iluminación cinematográfica de 4 fuentes y parallax suave con el mouse.
- **🌐 Sistema Multi-Idioma (i18n & RTL):** Soporte completo para **Árabe (`ar`)** con cambio dinámico de dirección de texto (`dir="rtl"`), **Inglés (`en`)** y **Español (`es`)**.
- **🐾 La Familia Felina Real (9 Vidas):** Tarjetas interactivas con *Gatito* (La Matriarca Serena), *Naranjosa* (La Reina Madre Valiente), *Tomy* (El Príncipe Explorador), *Manchas* (El Pequeño Guardián) y *La Camada Real* (los 5 recién nacidos).
- **🏆 Leaderboard & Calculadora de Ego:** Escala de generosidad no lineal desde **$100** hasta **$1,000,000 USD** (*Noble Patrocinador*, *Emir de la Compasión*, *Sultán Fundador* y *Gran Jeque Inmortal*).
- **💳 Bóveda de Tributos Multi-Canal:**
  - **Cripto / Web3 VIP:** USDT (TRC20 / BEP20), Bitcoin nativo (BTC) y Binance Pay (0% comisión).
  - **PayPal Internacional:** Pago rápido en USD.
  - **Transferencia Internacional (Wire Transfer):** BCP en Dólares con código SWIFT/BIC y CCI.
  - **Donaciones Locales (Perú):** Acordeón discreto para Yape y BCP Soles.
- **🔍 SEO Técnico & Social Sharing:** Metadatos OpenGraph (1200x630), Twitter Cards, `robots.txt`, `sitemap.xml` y Schema.org JSON-LD (`@graph` con `WebSite`, `Person` y `DonateAction`).

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 semántico, CSS3 Vanilla (variables, grid, flexbox, animaciones CSS).
- **Interactividad & 3D:** JavaScript Vanilla (ES6+), Three.js r128 (vía CDN asíncrono).
- **Tipografías:** *Cinzel* (títulos de lujo), *Cairo* (árabe y modernidad), *Plus Jakarta Sans* (lectura limpia).
- **Despliegue:** Optimizado para Vercel, Netlify o GitHub Pages.

---

## 🚀 Despliegue Rápido

1. Clona el repositorio:
   ```bash
   git clone https://github.com/cristhiancg9x-coder/AL-MEOW-PALACE.git
   ```
2. Abre `index.html` en cualquier navegador web moderno o sírvelo con una extensión de servidor local (ej. Live Server).
3. Para configurar tus propias wallets y cuentas de pago, edita el objeto `PAYMENT_CONFIG` en la cabecera de `app.js`.
